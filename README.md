# DOLCE-CUORE
Dolce Cuore es un proyecto innovador enfocado en el bienestar emocional y la salud mental de niños y adolescentes. Nuestra propuesta consiste en un peluche interactivo diseñado para brindar apoyo emocional, compañía y tranquilidad a jóvenes que enfrentan estrés, ansiedad o presión emocional en su vida diaria.
